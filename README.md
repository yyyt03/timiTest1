# 王者荣耀觉醒之战小助手

## 项目概述
微信小程序，为王者荣耀觉醒之战模式提供英雄攻略推荐和方案创作功能。

## 技术架构

### 前端架构
- **框架**: 微信小程序原生开发
- **语言**: TypeScript
- **样式**: WXSS
- **状态管理**: 页面级状态管理

### 后端架构
- **云平台**: 微信云开发
- **数据库**: 云数据库
- **存储**: 云存储
- **函数**: 云函数

## 页面结构

### 1. 主页面 (Tabbar)

#### 1.1 攻略页面 (`pages/strategy/strategy`)
- **功能**: 小程序主入口页面
- **布局**:
  - 顶部轮播图展示区
  - 2x2网格功能卡片区
- **功能卡片**:
  - 推荐方案
  - 英雄分类
  - 体验服方案
  - 方案创作

#### 1.2 用户页面 (`pages/user/user`)
- **功能**: 用户个人中心
- **布局**:
  - 用户信息展示区（头像、昵称）
  - 功能卡片列表
- **功能卡片**:
  - 收藏方案
  - 创作方案

### 2. 功能页面

#### 2.1 英雄分类页面 (`pages/heroCategory/heroCategory`)
- **功能**: 按分类展示英雄列表
- **英雄分类**:
  - 射手
  - 辅助
  - 刺客
  - 战士
  - 法师
- **交互**: 点击英雄头像进入方案创作

#### 2.2 方案创作页面 (`pages/createPlan/createPlan`)
- **功能**: 创建英雄攻略方案
- **创作流程**:
  1. 选择英雄
  2. 选择流派核心（技能1/2/3核心）
  3. 选择特性天赋（最多3个）
  4. 填写出装推荐
  5. 填写装备密语（选填）
  6. 填写方案思路描述
  7. 生成一图流方案

#### 2.3 推荐方案页面 (`pages/recommendPlan/recommendPlan`)
- **功能**: 展示推荐攻略方案
- **状态**: 待完善

#### 2.4 体验服方案页面 (`pages/betaPlan/betaPlan`)
- **功能**: 展示体验服攻略方案
- **状态**: 待完善

#### 2.5 英雄攻略页面 (`pages/heroPlan/heroPlan`)
- **功能**: 展示特定英雄的攻略详情
- **状态**: 待完善

## 数据库设计

### 数据集合

#### 1. 英雄分类集合 (`hero_categories`)
- **权限**: 所有用户可读，仅创建者可写
- **字段**:
  - `key`: 分类键名
  - `name`: 分类显示名称
  - `order`: 排序权重
  - `createTime`: 创建时间
  - `updateTime`: 更新时间

#### 2. 英雄集合 (`heroes`)
- **权限**: 所有用户可读，仅创建者可写
- **字段**:
  - `_id`: 英雄唯一标识符
  - `name`: 英雄名称
  - `category`: 所属分类
  - `avatar`: 英雄头像URL
  - `description`: 英雄描述
  - `difficulty`: 难度等级(1-5)
  - `createTime`: 创建时间
  - `updateTime`: 更新时间

#### 3. 用户集合 (`users`)
- **权限**: 仅创建者可读写
- **字段**:
  - `_id`: 用户唯一标识符
  - `openid`: 微信openid
  - `appid`: 微信appid
  - `unionid`: 微信unionid
  - `nickName`: 用户昵称
  - `avatarUrl`: 用户头像URL
  - `createTime`: 创建时间
  - `updateTime`: 更新时间

#### 4. 攻略集合 (`plans`)
- **权限**: 所有用户可读，仅创建者可写
- **字段**:
  - `_id`: 攻略唯一标识符
  - `heroId`: 关联英雄ID
  - `heroName`: 英雄名称
  - `creatorId`: 创建者用户ID
  - `creatorName`: 创建者昵称
  - `title`: 攻略标题
  - `description`: 攻略描述
  - `coreSkill`: 核心技能
  - `talents`: 天赋选择数组
  - `equipment`: 装备搭配
  - `equipmentCode`: 装备代码
  - `strategy`: 策略说明
  - `imageUrl`: 攻略图片URL
  - `likes`: 点赞数
  - `favorites`: 收藏数
  - `views`: 浏览量
  - `status`: 状态
  - `createTime`: 创建时间
  - `updateTime`: 更新时间

#### 5. 点赞集合 (`likes`)
- **权限**: 仅创建者可读写
- **字段**:
  - `_id`: 点赞记录唯一标识符
  - `userId`: 用户ID
  - `planId`: 攻略ID
  - `createTime`: 创建时间

#### 6. 收藏集合 (`favorites`)
- **权限**: 仅创建者可读写
- **字段**:
  - `_id`: 收藏记录唯一标识符
  - `userId`: 用户ID
  - `planId`: 攻略ID
  - `createTime`: 创建时间

## 部署说明

### 本地开发
1. 克隆项目到本地
2. 使用微信开发者工具打开项目
3. 配置云开发环境
4. 上传云函数
5. 导入数据库数据

### 云函数部署
1. 在微信开发者工具中右键云函数目录
2. 选择"上传并部署：云端安装依赖"
3. 等待部署完成

### 数据库初始化
1. 在云开发控制台创建数据库集合
2. 设置集合权限
3. 导入json_make目录中的数据文件
