# 觉醒天赋推荐（小程序）
本项目为微信小程序，核心功能是展示游戏“王者荣耀”觉醒之战模式的流派加点推荐，以及装备推荐。采用分层模块化开发，便于维护和扩展。

- 每次对话检查优化部分第一条并尝试实现。
- 所有图片资源都需要在云平台上传，获取使用（除了icons

## 📋 项目分层与主要模块

### 1. 页面层
- ✅ Tabbar设计：分为两个Tabbar，分别是【攻略】+【用户】
- ✅ 攻略页面：
  - 顶部为长方形多图展示区（约占页面25%，默认展示文字“觉醒之战小助手”）
  - 向下滑为2x2卡片式主要功能区，功能分别为【推荐方案】【英雄分类】【体验服方案】【方案创作】
- ✅ 用户页面：
  - 自动读取微信用户信息，显示头像
  - 下方1x2卡片，内容为【收藏方案】【创作方案】

### 2. 功能模块
- [ ] 推荐方案页面（待完善）
- [ ] 体验服方案页面（待完善）
- ✅ 英雄分类：
  - 英雄分为射手、辅助、刺客、战士、法师
  - 射手：[孙尚香, 马可波罗, 后羿, 狄仁杰, 鲁班七号]
  - 辅助：[东皇太一, 钟馗, 明世隐, 瑶]
  - 刺客：[赵云, 李白, 典韦, 孙悟空]
  - 战士：[孙策, 司空震, 铠, 亚瑟, 程咬金, 吕布]
  - 法师：[杨玉环, 妲己, 诸葛亮, 安琪拉, 甄姬, 小乔, 武则天, 貂蝉]
- ✅ 方案创作：
  - 流程：选择英雄→选择流派核心（每个英雄3个核心, 对应三个技能）+特性天赋（每核心8个天赋，最多选3个）→出装推荐（文字描述）+装备密语（选填）→方案思路描述（如核心、前后期、发育、玩法等）→生成一图流方案
  - ✅ 方案创作流程优化：点击方案创作-进入英雄选择-点击英雄头像-直接进入后续方案创作
  - ✅ 选择流派核心时选中效果优化，与特性天赋一致
  - ✅ “从英雄分类中选择”已改为button按钮
