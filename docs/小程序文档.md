## 1. 项目概述

### 1.1 项目简介
"觉醒天赋推荐"是一款专为王者荣耀觉醒之战模式设计的攻略推荐小程序，主要提供英雄攻略、天赋搭配、装备推荐等服务。用户可以通过小程序获取专业的游戏攻略建议，创建个性化方案，并收藏喜欢的攻略。

### 1.2 核心功能
- **英雄攻略推荐** - 提供热门英雄的详细攻略
- **天赋搭配建议** - 根据英雄特点推荐最优天赋组合
- **装备推荐** - 提供装备搭配和出装建议
- **方案创建** - 用户可以创建个性化攻略方案
- **收藏功能** - 收藏喜欢的攻略方案
- **图片生成** - 生成攻略图片
- **智能筛选** - 支持按英雄、时间、热度等条件筛选方案
- **环境检测** - 开发环境下的特殊功能支持

### 1.3 目标用户
- 游戏玩家
- 攻略创作者
- 游戏社区用户

## 2. 功能详细说明

### 2.1 主要页面功能

#### 攻略页面 (strategy)
- **功能：** 小程序主入口页面，展示推荐攻略和快速入口
- **特色：**
  - 环境检测功能（仅在develop环境下显示创作功能）
  - 用户信息获取和显示
  - 推荐方案展示
  - 四个功能入口：推荐方案、英雄分类、体验服方案、方案创作
  - 云开发环境初始化检查

#### 用户页面 (user)
- **功能：** 用户信息管理和功能入口
- **特色：**
  - 用户登录/退出
  - 我的方案管理
  - 收藏方案查看
  - 方案创作入口
  - 环境检测（仅开发版显示管理员入口）
  - 云存储默认头像支持

#### 英雄分类页面 (heroCategory)
- **功能：** 英雄分类浏览和选择
- **特色：**
  - 英雄分类展示（射手、辅助、刺客、战士、法师）
  - 英雄搜索功能
  - 支持创建方案流程
  - 本地英雄数据管理

#### 方案创建页面 (createPlan)
- **功能：** 创建个性化攻略方案
- **特色：**
  - 英雄选择
  - 天赋配置（支持优先级标记）
  - 装备搭配（6个装备槽，支持装备联想和验证）
  - 攻略文字编辑
  - 体验服方案标记
  - 编辑模式支持
  - 环境检测功能
  - 敏感词检测（提交时一次性检测）

#### 推荐方案页面 (recommendPlan)
- **功能：** 展示推荐攻略方案
- **特色：**
  - 方案筛选功能（精选/最新）
  - 英雄筛选器
  - 方案卡片展示
  - 支持点赞和收藏操作
  - 下拉刷新和分页加载
  - 英雄分类统计

#### 体验服方案页面 (betaPlan)
- **功能：** 展示体验服攻略方案
- **特色：**
  - 体验服方案列表展示（精选/最新筛选）
  - 英雄筛选功能
  - 支持点赞和收藏操作
  - 下拉刷新和上拉加载更多

#### 英雄攻略页面 (heroPlan)
- **功能：** 展示特定英雄的攻略详情
- **特色：**
  - 英雄方案列表展示
  - 支持查看方案详情
  - 支持点赞和收藏操作
  - 快速创建该英雄的方案

#### 我的方案页面 (myPlans)
- **功能：** 用户个人方案管理
- **特色：**
  - 方案状态管理（草稿、已发布、审核中、已拒绝）
  - 编辑、删除、发布功能
  - 环境检测（仅开发版显示发布按钮）
  - 管理员审核模式
  - 英雄分类筛选
  - 下拉刷新和分页加载
  - 支持重新提交审核

#### 收藏页面 (favorites)
- **功能：** 用户收藏的方案列表
- **特色：**
  - 收藏方案列表展示
  - 英雄分类筛选功能
  - 支持取消收藏
  - 快速跳转到方案详情
  - 下拉刷新和分页加载

#### 方案详情页面 (planDetail)
- **功能：** 查看攻略方案详细信息
- **特色：**

## 项目总体描述

"觉醒天赋推荐"是一款专为王者荣耀觉醒之战模式设计的专业攻略推荐小程序。项目采用微信小程序原生开发架构，使用TypeScript语言和云开发技术栈，构建了完整的游戏攻略生态系统。

小程序核心功能包括英雄攻略推荐、天赋搭配建议、装备推荐、个性化方案创建、智能筛选和收藏管理等。项目架构包含10个功能页面、15个云函数服务、6个数据库集合，支持29个英雄的完整数据管理。

技术特色体现在云开发架构的稳定性和扩展性，TypeScript的类型安全保障，以及环境检测、敏感词过滤、图片生成等智能化功能。目标用户覆盖游戏玩家、攻略创作者和游戏社区用户，致力于为王者荣耀玩家提供专业、便捷的攻略服务体验。
