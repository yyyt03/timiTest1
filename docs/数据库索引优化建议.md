# 数据库索引优化建议

**更新时间：** 2025年08月4日 8:49:33

## 当前数据库查询分析

### favorites 集合
```javascript
// 当前查询
db.collection('favorites')
  .where({
    userId: currentUserId,
    planId: planId
  })
  .count()

db.collection('favorites')
  .where({
    planId: planId
  })
  .count()
```

**建议索引：**
```javascript
// 复合索引：userId + planId
db.collection('favorites').createIndex({
  userId: 1,
  planId: 1
})

// 单字段索引：planId
db.collection('favorites').createIndex({
  planId: 1
})
```

### likes 集合
```javascript
// 当前查询
db.collection('likes')
  .where({
    userId: currentUserId,
    planId: planId
  })
  .count()

db.collection('likes')
  .where({
    planId: planId
  })
  .count()
```

**建议索引：**
```javascript
// 复合索引：userId + planId
db.collection('likes').createIndex({
  userId: 1,
  planId: 1
})

// 单字段索引：planId
db.collection('likes').createIndex({
  planId: 1
})
```

### plans 集合
```javascript
// 当前查询
db.collection('plans')
  .doc(planId)
  .get()
```

**建议索引：**
```javascript
// 主键索引（通常自动创建）
// 如果需要按英雄查询，可以添加：
db.collection('plans').createIndex({
  heroId: 1
})
```

## 索引创建脚本

```javascript
// 在云函数中执行索引创建
const db = cloud.database();

// 创建 favorites 集合索引
await db.collection('favorites').createIndex({
  userId: 1,
  planId: 1
});

await db.collection('favorites').createIndex({
  planId: 1
});

// 创建 likes 集合索引
await db.collection('likes').createIndex({
  userId: 1,
  planId: 1
});

await db.collection('likes').createIndex({
  planId: 1
});

// 创建 plans 集合索引（如果需要按英雄查询）
await db.collection('plans').createIndex({
  heroId: 1
});
```

## 预期性能提升

- **查询速度提升**：50-80%
- **云函数执行时间**：减少 30-50%
- **数据库资源消耗**：减少 40-60%

## 注意事项

1. **索引创建时间**：大数据量时可能需要几分钟
2. **存储空间**：索引会占用额外存储空间
3. **写入性能**：索引会略微影响写入性能，但查询性能提升显著
4. **监控**：创建索引后需要监控查询性能
