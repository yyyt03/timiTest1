# 环境配置说明

## 概述

本项目已实现完整的微信小程序环境适配机制，支持 `develop`（开发版）、`trial`（体验版）和 `release`（线上版）三种环境的自动识别和配置。

## 环境类型说明

### 1. develop（开发版）
- **识别方式**: `__wxjs_environment === 'miniprogram'` 或 `wx.getAppBaseInfo().platform === 'devtools'`
- **特点**: 在微信开发者工具中运行
- **配置**: 开发环境配置，启用详细日志、短缓存时间、性能监控等

### 2. trial（体验版）
- **识别方式**: `__wxjs_environment === 'trial'`
- **特点**: 通过体验版二维码访问，用于测试
- **配置**: 使用生产环境配置，禁用开发特性

### 3. release（线上版）
- **识别方式**: `__wxjs_environment === 'release'`
- **特点**: 正式发布版本，用户通过搜索或分享访问
- **配置**: 使用专门的线上版配置，最长缓存时间，启用错误上报和数据分析

## 环境配置差异

| 配置项 | develop | trial | release |
|--------|---------|-------|---------|
| 日志输出 | ✅ 启用 | ❌ 禁用 | ❌ 禁用 |
| 缓存时间 | 5分钟 | 30分钟 | 60分钟 |
| 版本检查间隔 | 2分钟 | 5分钟 | 10分钟 |
| 调试模式 | ✅ 启用 | ❌ 禁用 | ❌ 禁用 |
| 性能监控 | ✅ 启用 | ❌ 禁用 | ❌ 禁用 |
| 错误上报 | ❌ 禁用 | ❌ 禁用 | ✅ 启用 |
| 数据分析 | ❌ 禁用 | ❌ 禁用 | ✅ 启用 |

## 核心功能

### 环境检测
```typescript
// 获取当前环境类型
const env = getCurrentEnvironment(); // 返回 Environment.DEVELOP/TRIAL/RELEASE

// 判断环境类型
isDevelopmentMode();  // 是否为开发环境
isTrialMode();        // 是否为体验版
isReleaseMode();      // 是否为线上版
isProductionMode();   // 是否为生产环境（trial + release）
```

### 配置获取
```typescript
// 获取当前环境的配置
const config = getCurrentConfig();

// 获取环境信息
const envInfo = getEnvironmentInfo();
```

### 日志工具
```typescript
// 普通日志（根据环境配置决定是否显示）
log('这是一条日志');

// 调试日志（仅在开发环境显示）
debugLog('这是调试信息');

// 性能监控（仅在开发环境显示）
const startTime = Date.now();
// ... 执行操作 ...
performanceLog('操作耗时', startTime);
```

## 环境适配优势

### 1. 自动环境识别
- 无需手动配置，系统自动识别运行环境
- 支持多种检测方式，确保环境识别的准确性

### 2. 差异化配置
- 开发环境：详细的调试信息和性能监控
- 体验版：生产环境配置，禁用开发特性
- 线上版：最优性能配置，启用生产特性

### 3. 安全性保障
- 生产环境完全禁用调试功能
- 敏感信息不会在生产环境中泄露
- 开发工具特有的功能不会影响生产环境

### 4. 性能优化
- 生产环境使用更长的缓存时间
- 减少不必要的版本检查频率
- 禁用开发环境的性能监控开销

## 使用示例

### 在页面中使用
```typescript
import { log, debugLog, getEnvironmentInfo } from '../../utils/config';

Page({
  onLoad() {
    // 获取环境信息
    const envInfo = getEnvironmentInfo();
    log(`当前环境: ${envInfo.environment}`);
    
    // 调试信息（仅在开发环境显示）
    debugLog('页面加载完成');
    
    // 根据环境执行不同逻辑
    if (envInfo.isDevelopment) {
      // 开发环境特有逻辑
      this.enableDebugMode();
    } else {
      // 生产环境逻辑
      this.enableProductionMode();
    }
  }
});
```

### 在工具类中使用
```typescript
import { log, isDevelopmentMode } from '../config';

export class HeroCache {
  async setCache(data: any) {
    // 根据环境决定缓存策略
    if (isDevelopmentMode()) {
      log('开发环境：设置缓存', data);
      // 开发环境：短时间缓存
      this.cacheExpireTime = 5 * 60 * 1000;
    } else {
      // 生产环境：长时间缓存
      this.cacheExpireTime = 30 * 60 * 1000;
    }
    
    // 设置缓存逻辑...
  }
}
```

## 注意事项

### 1. 环境变量
- `__wxjs_environment` 是微信小程序的内置环境变量
- 在开发者工具中可能为 `undefined`，需要额外的检测逻辑

### 2. 默认行为
- 当无法识别环境时，默认使用 `trial`（体验版）配置
- 这确保了生产环境的安全性

### 3. 配置更新
- 环境配置在应用启动时确定，运行时不会改变
- 如需动态配置，需要重新启动应用

### 4. 测试建议
- 开发环境：在微信开发者工具中测试
- 体验版：通过体验版二维码在真机上测试
- 线上版：通过正式发布版本测试

## 总结

本项目已完全实现环境适配机制：

1. **trial 体验版** 被视为生产环境，使用 `production` 配置
2. **develop 开发版** 使用开发环境配置，启用调试功能
3. **release 线上版** 使用专门的线上配置，最优性能
4. **自动环境识别**，无需手动配置
5. **安全性保障**，生产环境完全禁用开发特性

这样的配置确保了在不同环境中都能获得最佳的用户体验和性能表现。
