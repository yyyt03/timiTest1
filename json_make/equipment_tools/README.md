# 装备数据爬取工具

## 概述
此文件夹包含用于爬取和处理游戏装备数据的 Python 脚本和工具。

## 文件说明

### 🕷️ `download_equipment_simple.py`
- **用途**: 基础装备数据爬取脚本
- **功能**: 从游戏网站爬取装备基本信息
- **特点**: 简单易用，适合快速获取装备数据

### 🕷️ `download_equipment_data.py`
- **用途**: 完整装备数据爬取脚本
- **功能**: 爬取装备的详细信息，包括属性、价格、合成路径等
- **特点**: 数据更全面，包含装备的完整信息

### 🕷️ `download_equipment_enhanced.py`
- **用途**: 增强版装备数据爬取脚本
- **功能**: 在基础版本上增加了错误处理、重试机制、数据验证等功能
- **特点**: 更稳定可靠，适合大规模数据爬取

### 📋 `requirements.txt`
- **用途**: Python 依赖包列表
- **内容**: 列出运行爬虫脚本所需的 Python 包
- **安装**: `pip install -r requirements.txt`

### 📖 `README_equipment_scraper.md`
- **用途**: 装备爬虫工具的详细使用说明
- **内容**: 包含安装步骤、使用方法、注意事项和常见问题

## 使用流程

1. **安装依赖**: `pip install -r requirements.txt`
2. **选择脚本**: 根据需要选择合适的爬虫脚本
3. **运行爬虫**: `python download_equipment_*.py`
4. **查看结果**: 检查生成的 JSON 数据文件

## 脚本特点

### 基础版本 (`download_equipment_simple.py`)
- 快速获取装备基本信息
- 适合小规模数据爬取
- 代码简洁易懂

### 完整版本 (`download_equipment_data.py`)
- 获取装备的详细信息
- 包含属性、价格、合成路径等
- 数据更全面

### 增强版本 (`download_equipment_enhanced.py`)
- 增加错误处理和重试机制
- 支持断点续传
- 数据验证和清洗
- 适合大规模数据爬取

## 注意事项

- 请遵守网站的爬虫协议
- 建议设置适当的爬取间隔，避免对服务器造成压力
- 爬取的数据仅供学习和研究使用
- 如遇到网络问题，可以尝试使用增强版本的脚本

## 数据格式

爬取的装备数据通常包含以下字段：
- **装备名称**: 装备的中文名称
- **装备类型**: 攻击、防御、法术等
- **属性加成**: 攻击力、防御力、生命值等
- **价格**: 装备的购买价格
- **合成路径**: 需要的材料和合成方式
- **适用英雄**: 推荐使用的英雄类型
