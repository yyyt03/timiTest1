# 微信云平台 MongoDB 数据库导入 JSON 格式规范

## 1. 文件格式要求
- **文件后缀**：.json
- **编码格式**：UTF-8（无 BOM）
- **内容格式**：JSON Lines（每行一个对象，非数组）
- **每行结构**：一行一个完整的 JSON 对象，行与行之间无逗号、无数组包裹
- **文件结尾**：无多余空行

## 2. 时间字段格式
- 必须为 MongoDB 的 ISODate 对象格式：
```json
{"createTime": {"$date": "2025-07-28T20:25:00.882Z"}}
```

## 3. 示例
### 正确示例（每行为一个对象）
```json
{"key": "shooter", "name": "射手", "order": 1, "createTime": {"$date": "2025-07-28T20:25:00.882Z"}, "updateTime": {"$date": "2025-07-28T20:25:00.882Z"}}
{"key": "support", "name": "辅助", "order": 2, "createTime": {"$date": "2025-07-28T20:25:00.882Z"}, "updateTime": {"$date": "2025-07-28T20:25:00.882Z"}}
```

### 错误示例（数组包裹/逗号分隔）
```json
[
  {"key": "shooter", ...},
  {"key": "support", ...}
]
```

## 4. 注意事项
- 时间字段必须为 { "$date": "..." }，否则导入失败
- 键名不能以 . 开头或结尾，不能有连续的 .
- 键名不能重复，不能有歧义
- 文件必须为 UTF-8 编码
- 文件后缀必须为 .json
- 每行一个对象，行末无逗号
- 文件结尾无多余空行

## 5. 导入步骤
1. 在云开发控制台选择集合，点击“导入”
2. 选择 .json 文件，确认导入
3. 导入成功后检查数据完整性

如需生成其他集合数据，严格按照本规范编写 json 文件即可。
