# 英雄方案数据创建指南

## 概述
本指南帮助您快速创建英雄方案数据，通过简单的模板填写，自动转换为JSON格式，完全适配方案详情页面显示需求。

## 文件说明
- `plan_template.md` - 填写模板文件（已更新为详细格式）
- `convert_template_to_json.js` - 转换脚本（已适配新格式）
- `plans_data_fixed.json` - 现有方案数据
- `plans_data_updated.json` - 转换后的完整数据

## 使用步骤

### 1. 填写模板
打开 `plan_template.md` 文件，按照以下格式填写方案数据：

```
英雄：英雄名称
特性：
- 技能1：核心技能名称|核心技能描述|核心技能标签 + 天赋1名称|天赋1描述|天赋1标签,天赋2名称|天赋2描述|天赋2标签,天赋3名称|天赋3描述|天赋3标签
- 技能2：核心技能名称|核心技能描述|核心技能标签 + 天赋1名称|天赋1描述|天赋1标签,天赋2名称|天赋2描述|天赋2标签,天赋3名称|天赋3描述|天赋3标签
- 技能3：核心技能名称|核心技能描述|核心技能标签 + 天赋1名称|天赋1描述|天赋1标签,天赋2名称|天赋2描述|天赋2标签,天赋3名称|天赋3描述|天赋3标签
出装：装备1,装备2,装备3,装备4,装备5,装备6
密语：（可选，留空表示无）
思路：50字以内的策略说明
作者：作者名称
```

### 2. 填写示例
```
英雄：妲己
特性：
- 技能1：一技能强化|增强一技能伤害和控制效果|伤害提升 + 技能伤害提升|增加技能伤害|伤害,冷却缩减|减少技能冷却时间|冷却,法力回复|提升法力回复|回复
- 技能2：二技能强化|强化二技能控制效果|控制强化 + 控制时间延长|延长控制时间|控制,冷却缩减|减少技能冷却时间|冷却,法力回复|提升法力回复|回复
- 技能3：三技能强化|增强三技能爆发伤害|爆发强化 + 爆发伤害提升|增加爆发伤害|伤害,冷却缩减|减少技能冷却时间|冷却,法力回复|提升法力回复|回复
出装：破军,无尽战刃,泣血之刃,闪电匕首,贤者的庇护,抵抗之靴
密语：
思路：利用技能的高伤害和控制效果，在团战中打出爆发输出并控制敌方关键英雄。
作者：法师专家
```

### 3. 运行转换脚本
在 `json_make` 目录下运行：
```bash
node convert_template_to_json.js
```

### 4. 查看结果
转换完成后，会在 `plans_data_updated.json` 文件中生成完整的JSON数据。

## 数据字段说明

### 必填字段
- **英雄**：英雄的中文名称
- **特性**：每个技能的详细描述，包含核心技能和3个天赋
- **出装**：6个装备，用逗号分隔
- **思路**：策略说明，限制50字以内
- **作者**：方案创建者名称

### 可选字段
- **密语**：特殊代码或提示，可选

### 自动生成字段
- **ID**：自动生成的方案ID
- **英雄ID**：英雄的拼音标识
- **用户ID**：创建者的唯一标识
- **时间戳**：创建和更新时间
- **统计数据**：点赞数、浏览量等

## 技能描述格式详解

### 核心技能格式
```
技能名称|技能描述|技能标签
```

### 天赋格式
```
天赋名称|天赋描述|天赋标签
```

### 完整技能示例
```
一技能强化|增强一技能伤害和控制效果|伤害提升 + 技能伤害提升|增加技能伤害|伤害,冷却缩减|减少技能冷却时间|冷却,法力回复|提升法力回复|回复
```

## 方案详情页面适配

生成的JSON数据完全适配方案详情页面的显示需求：

- **英雄信息显示**：`heroName`, `heroId`, `creatorName` 用于显示英雄和作者信息
- **方案描述**：`description` 字段对应思路说明，显示在详情页面
- **技能展示**：`skillOne`, `skillTwo`, `skillThree` 包含详细的core和talents结构，支持技能详情展示
- **装备列表**：`equipment` 数组格式，便于装备图标和名称显示
- **统计信息**：`likes`, `views` 等统计数据用于显示方案热度

## 注意事项

1. **技能格式**：严格按照 `名称|描述|标签` 的格式填写
2. **装备数量**：必须填写6个装备
3. **思路长度**：控制在50字以内
4. **分隔符**：使用逗号分隔多个项目，使用|分隔描述字段
5. **英雄名称**：使用标准的中文名称
6. **标签系统**：使用统一的标签便于分类和显示
7. **数据验证**：转换脚本会自动验证数据完整性

## 常见问题

### Q: 技能描述格式错误怎么办？
A: 确保使用 `名称|描述|标签` 的格式，每个字段都不能为空。

### Q: 装备数量不是6个怎么办？
A: 转换脚本会验证装备数量，必须填写6个装备。

### Q: 生成的JSON可以直接使用吗？
A: 是的，生成的JSON数据完全适配方案详情页面，可以直接导入数据库使用。

### Q: 如何添加新的英雄？
A: 在模板中添加新的方案数据，运行转换脚本即可生成对应的JSON数据。
