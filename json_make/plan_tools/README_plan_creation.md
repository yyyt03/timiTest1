# 英雄方案数据创建指南

## 概述
本指南帮助您快速创建英雄方案数据，通过简单的模板填写，自动转换为JSON格式。

## 文件说明
- `plan_template.md` - 填写模板文件
- `convert_template_to_json.js` - 转换脚本
- `plans_data_fixed.json` - 现有方案数据
- `plans_data_updated.json` - 转换后的完整数据

## 使用步骤

### 1. 填写模板
打开 `plan_template.md` 文件，按照以下格式填写方案数据：

```
英雄：英雄名称
特性：
- 技能1：核心技能描述 + 天赋1,天赋2,天赋3
- 技能2：核心技能描述 + 天赋1,天赋2,天赋3
- 技能3：核心技能描述 + 天赋1,天赋2,天赋3
出装：装备1,装备2,装备3,装备4,装备5,装备6
密语：（可选，留空表示无）
思路：50字以内的策略说明
作者：作者名称
```

### 2. 填写示例
```
英雄：妲己
特性：
- 技能1：一技能强化 + 技能伤害提升,冷却缩减,法力回复
- 技能2：二技能强化 + 控制时间延长,冷却缩减,法力回复
- 技能3：三技能强化 + 爆发伤害提升,冷却缩减,法力回复
出装：破军,无尽战刃,泣血之刃,闪电匕首,贤者的庇护,抵抗之靴
密语：
思路：利用技能的高伤害和控制效果，在团战中打出爆发输出并控制敌方关键英雄。
作者：法师专家
```

### 3. 运行转换脚本
在 `json_make` 目录下运行：
```bash
node convert_template_to_json.js
```

### 4. 查看结果
转换完成后，会在 `plans_data_updated.json` 文件中生成完整的JSON数据。

## 数据字段说明

### 必填字段
- **英雄**：英雄的中文名称
- **特性**：每个技能的核心强化和3个天赋
- **出装**：6个装备，用逗号分隔
- **思路**：策略说明，限制50字以内
- **作者**：方案创建者名称

### 可选字段
- **密语**：特殊代码或提示，可选

### 自动生成字段
- **ID**：自动生成的方案ID
- **英雄ID**：英雄的拼音标识
- **装备代码**：6位数字代码
- **创建者ID**：用户标识
- **统计数据**：点赞数、收藏数、浏览量
- **时间戳**：创建和更新时间

## 注意事项

1. **技能格式**：每个技能必须包含核心技能描述和3个天赋
2. **装备数量**：必须填写6个装备
3. **思路长度**：控制在50字以内
4. **分隔符**：使用逗号分隔多个项目
5. **英雄名称**：使用标准的中文名称

## 常见问题

### Q: 如何添加新的英雄支持？
A: 在 `convert_template_to_json.js` 文件的 `generateHeroId` 函数中添加映射关系。

### Q: 转换失败怎么办？
A: 检查模板格式是否正确，确保所有必填字段都已填写。

### Q: 如何修改现有数据？
A: 直接编辑 `plans_data_fixed.json` 文件，或使用模板重新生成。

## 数据验证
转换脚本会自动验证：
- 必填字段完整性
- 技能数量（3个）
- 装备数量（6个）
- 思路长度（50字以内）

如有问题，会在控制台显示警告信息。
