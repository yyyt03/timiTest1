# 英雄方案数据填写模板

## 填写说明
请按照以下格式填写方案数据，每个方案用 `---` 分隔。

## 模板格式
```
英雄：英雄名称
特性：
- 技能1：核心技能名称|核心技能描述|核心技能标签 + 天赋1名称|天赋1描述|天赋1标签,天赋2名称|天赋2描述|天赋2标签,天赋3名称|天赋3描述|天赋3标签
- 技能2：核心技能名称|核心技能描述|核心技能标签 + 天赋1名称|天赋1描述|天赋1标签,天赋2名称|天赋2描述|天赋2标签,天赋3名称|天赋3描述|天赋3标签
- 技能3：核心技能名称|核心技能描述|核心技能标签 + 天赋1名称|天赋1描述|天赋1标签,天赋2名称|天赋2描述|天赋2标签,天赋3名称|天赋3描述|天赋3标签
出装：装备1,装备2,装备3,装备4,装备5,装备6
密语：（可选，如果没有请留空）
思路：50字以内的策略说明
作者：作者名称
```

## 示例
```
英雄：孙尚香
特性：
- 技能1：一技能强化|提升一技能伤害和射程|伤害提升 + 暴击率提升|增加暴击率|暴击,攻速加成|提升攻击速度|攻速,移速提升|增加移动速度|移速
- 技能2：二技能强化|强化二技能效果|技能强化 + 攻速加成|提升攻击速度|攻速,冷却缩减|减少技能冷却时间|冷却,移速提升|增加移动速度|移速
- 技能3：三技能强化|增强三技能威力|技能强化 + 技能伤害提升|增加技能伤害|伤害,冷却缩减|减少技能冷却时间|冷却,法力回复|提升法力回复|回复
出装：无尽战刃,破军,泣血之刃,闪电匕首,贤者的庇护,抵抗之靴
密语：
思路：利用一技能强化后的高暴击率，配合装备的暴击加成，在团战中打出爆炸伤害。
作者：王者大神
```
