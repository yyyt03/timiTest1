# 英雄方案数据填写模板

## 填写说明
请按照以下格式填写方案数据，每个方案用 `---` 分隔。

## 模板格式
```
英雄：英雄名称
特性：
- 技能1：核心技能描述 + 3个天赋（用逗号分隔）
- 技能2：核心技能描述 + 3个天赋（用逗号分隔）
- 技能3：核心技能描述 + 3个天赋（用逗号分隔）
出装：装备1,装备2,装备3,装备4,装备5,装备6
密语：（可选，如果没有请留空）
思路：50字以内的策略说明
作者：作者名称
```

## 示例
```
英雄：孙尚香
特性：
- 技能1：一技能强化 + 暴击率提升,攻速加成,移速提升
- 技能2：二技能强化 + 攻速加成,冷却缩减,移速提升
- 技能3：三技能强化 + 技能伤害提升,冷却缩减,法力回复
出装：无尽战刃,破军,泣血之刃,闪电匕首,贤者的庇护,抵抗之靴
密语：
思路：利用一技能强化后的高暴击率，配合装备的暴击加成，在团战中打出爆炸伤害。
作者：王者大神
```
