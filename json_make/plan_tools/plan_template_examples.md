# 英雄方案数据填写示例

## 填写格式说明
每个方案包含以下字段：
- 英雄：英雄名称
- 特性：3个技能，每个技能包含详细的技能描述和天赋信息
- 出装：6个装备，用逗号分隔
- 密语：可选的特殊代码
- 思路：50字以内的策略说明
- 作者：方案创建者

## 技能描述格式
技能格式：`核心技能名称|核心技能描述|核心技能标签 + 天赋1名称|天赋1描述|天赋1标签,天赋2名称|天赋2描述|天赋2标签,天赋3名称|天赋3描述|天赋3标签`

## 装备格式说明

生成的JSON数据中，装备格式为对象数组：
```json
"equipment": [
  {"name": "破军", "icon": "sword"},
  {"name": "无尽战刃", "icon": "blade"},
  {"name": "泣血之刃", "icon": "bloodblade"},
  {"name": "闪电匕首", "icon": "dagger"},
  {"name": "贤者的庇护", "icon": "shield"},
  {"name": "抵抗之靴", "icon": "boots"}
]
```

### 防御装备

- 冷静之靴 → cool_boots

## 注意事项

1. **技能格式**：每个技能必须包含核心技能和3个天赋的详细描述
2. **描述格式**：使用 `名称|描述|标签` 的格式
3. **装备数量**：必须填写6个装备
4. **思路长度**：控制在50字以内
5. **分隔符**：使用逗号分隔多个项目，使用|分隔描述字段
6. **英雄名称**：使用标准的中文名称
7. **密语**：可选，留空表示无特殊代码
8. **标签系统**：使用统一的标签便于分类和显示
