# 英雄方案数据填写示例

## 填写格式说明
每个方案包含以下字段：
- 英雄：英雄名称
- 特性：3个技能，每个技能包含核心强化和3个天赋
- 出装：6个装备，用逗号分隔
- 密语：可选的特殊代码
- 思路：50字以内的策略说明
- 作者：方案创建者

## 注意事项

1. **技能格式**：每个技能必须包含核心技能描述和3个天赋
2. **装备数量**：必须填写6个装备
3. **思路长度**：控制在50字以内
4. **分隔符**：使用逗号分隔多个项目
5. **英雄名称**：使用标准的中文名称
6. **密语**：可选，留空表示无特殊代码
